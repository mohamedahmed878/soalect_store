# SOALECT Admin Dashboard

لوحة تحكم متصلة بالكامل بالباك إند الحقيقي (backend/) — MongoDB عن طريق
Express API، مع تسجيل دخول أدمن حقيقي (JWT + role check) ومزامنة حية عن طريق
Socket.io.

## تشغيلها

الباك إند لازم يكون شغال الأول (شوف backend/README.md). بعدين:

```bash
cd admin
cp .env.example .env    # لو محتاج تغيّر رابط الـ API
npm install
npm run dev
```

هتفتح على http://localhost:5174

## تسجيل الدخول

لازم يكون عندك حساب بـ role="admin" في قاعدة البيانات. اعمل ده مرة واحدة من
مجلد backend:

```bash
npm run seed:admin
```

هيستخدم `ADMIN_EMAIL` و `ADMIN_PASSWORD` من `backend/.env`. أي حساب مش عليه
role="admin" هيترفض تسجيل الدخول هنا حتى لو البيانات صحيحة.

## الصفحات

- **الرئيسية** — إحصائيات حية (إيرادات، طلبات، منتجات، عملاء) + أحدث الطلبات
- **المنتجات** — إضافة / تعديل / حذف منتج، السعر، المخزون، الألوان، المقاسات،
  وروابط صور (رفع ملفات حقيقي محتاج إضافة multer للباك إند لاحقًا)
- **الطلبات** — عرض كل الطلبات وتغيير حالتها. أي تغيير بيوصل فورًا لحساب
  العميل صاحب الطلب في المتجر (عن طريق Socket.io)
- **العملاء** — كل العملاء المسجلين فعليًا في قاعدة البيانات

## المزامنة الحية

الصفحة دي بتنضم لـ "admin room" في Socket.io وبتسمع لحدثين:
- `order:new` — طلب جديد وصل، يتحط فوق قائمة الطلبات فورًا
- `order:updated` — حالة طلب اتغيرت (من تاب أدمن تاني مثلًا)، تتحدث في الجدول فورًا
